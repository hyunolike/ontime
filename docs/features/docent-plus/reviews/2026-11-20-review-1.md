# 1차 EGM 검토 (2026-11-20)

검토자: egm-implementation-readiness 한 명. 새 문맥에서 spec, design과 관련 코드만 받았다. 판정은 "아직 구현 불가"였고 blocker 2, major 10, minor 7건이었다.

| 지적 | 조치 |
|---|---|
| 음성 객체를 도슨트와 OnTimeSession이 함께 써서, 준비 전 질문이 멈출 수 있음 | 도슨트 전용 인스턴스 |
| STT의 무응답이 `false`라 버튼 누르기 전에 질문이 닫힘 | `listenYesNo(): Boolean?`, 10초 제한을 세션이 따로 가짐 |
| E2 문구가 spec, design, 테스트에서 다름. 테스트 컴파일 실패 | 문구를 하나로 맞춤. 컴파일 실패는 검토 시점에 구현 중이던 상태였고 지금은 통과 |
| pleos 도슨트의 차량 값이 재생기라 SDK 충전 값을 합칠 곳이 없음, 시험 값 표시 불가 | `ReplayVehicle`, `ChargeState.simulated` |
| SDK API 이름 미확인, `CAR_ENERGY` 권한 누락 | javap로 이름 확인, 권한 추가 |
| 몽촌토성 추가로 기존 "세 곳" 테스트가 깨짐 | 테스트 수정 항목에 넣음 |
| 관광공사 장소가 맨 앞이면 출처 칩이 사라짐 | 칩은 경로 출처를 따름, 해설 출처는 화면에 따로 |
| 관광공사 장소로 도장 칸이 수십 개 | 관광공사 장소 최대 6곳, 도장 칸 최대 4칸 |
| `platform-tour` 모듈 구성, 직렬화 라이브러리, 권한, 조회 수, 스레드 미정 | design "TourAPI" 절에 확정 |
| BuildConfig가 꺼져 있음, 음성 준비 여부가 화면과 어긋남 | `buildConfig = true`, `voice`를 StateFlow로 |
| 이어 가기에서 장소 목록이 없고 경유지 복원이 위험 | 목록을 입력으로 받음, 경유지는 복원하지 않음 |
| 관광공사 출처가 음성에도 섞임 | 화면에만 표시 |
| 회전 조건이 실제로 거의 안 걸림 | 문서에 명시 |
| 소수점에서 첫 문장이 잘림 | 공백 앞 문장부호 기준으로 자름 |
| 같은 사진이 두 곳에 나옴 | 같은 장소의 사진이라 유지 |
| fake 빌드 저장 여부 분기 없음 | `DocentBundle.remember` |
| tasks.md 없음 | 작성 |
| 키가 APK에 들어감 | 로컬 시연용으로 한정, 제출 APK는 키 없이 빌드 |
