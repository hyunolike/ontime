# 길벗 앱 아이콘 콘셉트

[비교 페이지](preview.html)에서 현재 아이콘과 A, B, C, A2, D 다섯 안을 512px, 96px, 48px로 볼 수 있습니다. 각 크기마다 어두운 배경과 밝은 배경을 함께 배치했습니다.

## A — 길 옆 이야기

앞으로 좁아지는 도로 오른쪽에 초록색 말풍선을 놓았습니다. 도로와 이야기를 나란히 보여 주어, 곧 지나갈 장소의 해설을 미리 들려주는 길벗의 역할을 나타냅니다.

## B — 오른쪽에 보일 장소

앞으로 뻗는 도로 오른쪽에 초록색 장소 핀을 세웠습니다. 핀이 도로 한쪽에 분명히 떨어져 있어, 진행 방향을 기준으로 어느 쪽 창밖을 볼지 알려 주는 기능을 강조합니다.

## C — 이야기가 되는 길

말풍선의 아래쪽이 넓어지며 도로로 이어지도록 하나의 윤곽으로 그렸습니다. 길을 따라 이야기가 이어진다는 뜻을 담았고, 큰 말풍선 실루엣으로 작은 크기에서도 해설 앱의 성격을 드러냅니다.

## 제작 기준과 검증

- 기존 `../icon.svg`의 바깥 512 좌표계, 모서리 반경 112 배경, 안쪽 `viewBox="18 18 72 72"` 구조를 따랐습니다.
- 배경 #0B0F14, 강조 #3DDC97, 보조 #E7EEF4만 사용했습니다. 선 굵기는 6이며 끝과 연결부는 둥글게 처리했습니다.
- 도형 수는 A 4개, B 4개, C 3개입니다. 배경 사각형은 제외했습니다.
- 선의 모든 끝점과 베지어 제어점에 반경 3을 더한 보수적 경계는 A 28.4558, B 27.8395, C 28.4558 이하로, (54,54) 중심의 반경 29 안전 영역 안에 있습니다. B의 원호와 채운 점도 별도로 포함해 검사했습니다.
- PNG는 `rsvg-convert`로 512×512 크기로 내보냈습니다.
- 48px 렌더를 밝은 배경과 어두운 배경에서 비교했습니다. A의 중앙 차선이 가장자리와 붙어 보여 짧은 한 줄로 정리했습니다. B의 핀과 C의 말풍선 윤곽도 작은 크기에서 확인했습니다.
- 기존 A, B, C 파일과 현재 앱 아이콘은 그대로 유지했습니다. 추가 작업에서는 이 README와 preview.html을 갱신했으며 앱에 적용하거나 커밋하지 않았습니다.

## A2 — 길 옆 이야기, 대칭 도로

기존 A의 도로를 중심축에 맞춘 대칭 원근으로 다듬고 중앙 차선을 없앴습니다. 오른쪽 위의 초록색 말풍선은 꼬리를 오른쪽 길가로 향하게 해, 곧 그쪽 창밖에 나타날 장소의 이야기를 들려준다는 뜻을 담았습니다.

## D — 길잡이 깃발 (주 후보)

A2와 같은 대칭 도로의 오른쪽에 초록색 깃대를 세우고 작은 삼각 깃발을 달았습니다. 패키지여행에서 가이드의 깃발을 따라가는 모습을 빌려, 길벗이 진행 방향의 어느 쪽을 볼지 짚어 주는 동행자라는 뜻을 담았습니다. 깃발을 오른쪽 위에 모으고 도로를 아래로 펼쳐 전체 형태의 시각적 중심을 맞췄습니다.

## A2와 D의 안전 영역 및 48px 검증

두 안의 도로는 `(37,73) → (49,51)`, `(71,73) → (59,51)`로 중심축 `x=54`에 대칭입니다. D는 깃대 `(69,37) → (69,52)`와 채운 삼각 천 `(69,34) → (78,39) → (69,44)`를 더한 4개 도형입니다. A2는 도로 위 오른쪽에 `x=55…73, y=34…44`인 말풍선과 `(70,50)`으로 내려가는 꼬리를 더한 3개 도형입니다.

중심 `(54,54)`으로부터 각 끝점과 곡선 극점의 거리를 계산했습니다. 선 도형은 둥근 끝과 연결부를 포함하도록 반경 3을 더했고, 선이 없는 채운 깃발 천은 반경을 더하지 않았습니다. 이차 베지어는 x/y 극점과 `d(r²)/dt=0`의 모든 내부 실근을 확인했습니다. 아래 값은 모두 선 반경을 반영한 최종 경계입니다.

| 도형 | 최대 반경 | 반경 29까지 여유 |
|---|---:|---:|
| 공통 도로 왼쪽 | 28.495098 | 0.504902 |
| 공통 도로 오른쪽 | 28.495098 | 0.504902 |
| A2 말풍선 | 28.467627 | 0.532373 |
| D 깃대 | 25.671568 | 3.328432 |
| D 깃발 천 (채움, 선 없음) | 28.301943 | 0.698057 |

끝점별 수치는 다음과 같습니다. 같은 좌표가 다시 등장하는 닫힌 경로에서는 한 번만 표기했습니다.

| 도형 | 끝점 좌표 → 최종 반경 |
|---|---|
| 왼쪽 도로 | `(37,73)` → 28.495098; `(49,51)` → 8.830952 |
| 오른쪽 도로 | `(71,73)` → 28.495098; `(59,51)` → 8.830952 |
| 깃대 | `(69,37)` → 25.671568; `(69,52)` → 18.132746 |
| 깃발 천 | `(69,34)` → 25.000000; `(78,39)` → 28.301943; `(69,44)` → 18.027756 |
| 말풍선 윗부분 | `(61,34)` → 24.189620; `(67,34)` → 26.853721; `(73,40)` → 26.600847 |
| 말풍선 오른쪽과 꼬리 | `(70,44)` → 21.867962; `(70,50)` → 19.492423; `(64,44)` → 17.142136 |
| 말풍선 왼쪽 | `(61,44)` → 15.206556; `(55,39)` → 18.033296 |

말풍선 곡선 내부의 반경 극점은 `(71.398322,35.401656)`에서 28.467627(최대), `(57.876727,43.526993)`에서 14.167493(최소)입니다. x/y 극점은 곡선 끝점과 일치하며, 선 도형의 내부 반경 극점까지 포함한 계산 기록은 [verification-a2-d.json](verification-a2-d.json)에 있습니다. 두 아이콘 모두 안전 영역을 벗어나는 도형이 없습니다.

`rsvg-convert`로 512px와 48px PNG를 각각 직접 렌더링했습니다. [48px 확인 이미지](legibility-a2-d-48.png)를 실제 픽셀 크기로 열어 어두운 배경과 밝은 배경을 확인했습니다. D에서는 삼각 천과 아래로 이어지는 깃대가 보이며, A2에서는 말풍선 안쪽 구멍과 오른쪽으로 내려가는 꼬리가 남습니다. 도로와 초록 표식 사이의 간격도 두 안 모두 유지됩니다.

비교 페이지는 현재 아이콘, A, B, C, A2, D 순서로 각 512/96/48px를 어두운 배경과 밝은 배경에 표시합니다(총 36개 이미지). 기존 A/B/C SVG와 PNG의 SHA-256 일치를 확인했습니다. 검증을 다시 실행하려면 `python3 docs/images/icon-concepts/verify-a2-d.py`를 사용합니다(NumPy, Pillow, rsvg-convert 필요).
