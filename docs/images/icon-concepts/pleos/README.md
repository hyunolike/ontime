# 길벗 — Pleos Connect 아이콘 시안

[비교 페이지](preview.html)에는 제공된 Pleos 레퍼런스를 먼저 놓고, 내비게이션과 전화, 차량 설정을 본뜬 대체 아이콘 사이에서 각 시안을 96px와 48px로 비교하도록 구성했습니다. [렌더 모음](inspection.png)에서는 회색과 녹색 타일을 48px, 96px, 512px로 볼 수 있습니다.

## P1 — 길을 품은 말풍선

흰 말풍선 안을 굽은 도로 모양으로 비워, 앞으로 지나갈 길의 이야기를 들려주는 기능을 담았습니다. 말풍선의 넓은 면과 아래로 벌어지는 도로가 작은 크기에서도 남으며, 흰 단색 실루엣과 회색 타일이 Pleos 기본 앱의 표현 방식에 어울립니다.

## P2 — 길가의 가이드 깃발

짧은 도로 옆에 패키지여행 가이드의 사각 깃발을 세웠습니다. 위아래 가장자리가 함께 출렁이는 넓은 천으로 삼각 골프 깃발과 구분하고, 도로와 깃대를 하나의 흰 면으로 연결해 Pleos 아이콘의 단순한 실루엣을 따랐습니다.

## P3 — 이야기가 보이는 차창

옆 유리창을 넓은 흰 면으로 그리고, 한쪽 창의 반짝임을 음각으로 넣었습니다. 어느 쪽 창밖을 볼지 알려 주는 길벗의 역할을 나타내며, 굵은 창틀과 채워진 유리 면으로 가는 선 없이 형태를 유지합니다.

## 색상과 대비

타일은 512×512이며 모서리 반경은 요청한 40px입니다. 회색은 Pleos 기본 앱에 맞춘 `#353535`, 녹색은 브랜드 민트 `#3DDC97`의 색상 계열을 유지하면서 밝기를 낮춘 `#1A9365`입니다. 모든 글리프는 순백색 `#FFFFFF`만 사용했습니다.

| 흰 글리프와 배경 | WCAG 대비 | 용도 |
|---|---:|---|
| `#353535` | 12.2662:1 | 시스템 회색 타일 |
| `#1A9365` | 3.8851:1 | 브랜드 녹색 타일, 요구 기준 3:1 충족 |
| `#3DDC97` | 1.7673:1 | 원래 민트와 비교, 타일에는 사용하지 않음 |

sRGB 성분을 선형화한 뒤 상대 휘도 `L = 0.2126R + 0.7152G + 0.0722B`를 구하고, `(L밝음 + 0.05) / (L어두움 + 0.05)`로 계산했습니다. 수치는 단색 면의 대비이며 가장자리의 안티앨리어싱 픽셀은 제외합니다. 브랜드의 어두운 색 `#0B0F14` 대신 이번 비교에서는 요청한 시스템 회색과 라이브러리의 검정 `#000000`을 사용했습니다.

## 크기와 안전 영역

각 타일과 foreground는 동일한 108 좌표계의 경로를 사용합니다. 타일에서는 경로를 `512/108`배 확대했고, foreground에서는 `viewBox="0 0 108 108"`로 배경 없이 그대로 배치했습니다. 512px 타일에서의 글리프 너비는 P1이 53.70%, P2와 P3가 각각 50.00%입니다.

안전 영역은 중심 `(54,54)`, 반경 `33`인 원입니다. 모든 끝점과 베지어 제어점이 이 원 안에 있으며, 원이 볼록 집합이고 곡선이 제어점의 볼록 껍질 안에 놓이므로 경로 전체가 안전 영역 안에 있습니다. 아래 수치는 실제 곡선의 최대 반경이 아닌, 제어점까지 포함한 보수적 상한입니다.

| 시안 | 반경 상한 | 반경 33까지 여유 |
|---|---:|---:|
| P1 | 32.6497dp | 0.3503dp |
| P2 | 32.8024dp | 0.1976dp |
| P3 | 32.4500dp | 0.5500dp |

2160px로 별도 렌더링한 foreground의 불투명 픽셀 위치도 반경 33 안에 들어오는지 확인합니다. SVG는 흰색으로 채운 단일 경로와 `fill-rule="evenodd"`만 사용하며, 선이나 마스크, 필터, 글리프 내부 그라데이션이 없습니다. Android VectorDrawable에서는 같은 경로를 `pathData`에 넣고 `fillColor="#FFFFFFFF"`, `fillType="evenOdd"`로 지정할 수 있습니다.

## 렌더 검토

제공된 실제 레퍼런스를 열어 회색 타일과 흰 실루엣의 관계를 확인했습니다. 여섯 타일 모두 `rsvg-convert`로 512px와 48px를 각각 직접 렌더링했으며, PNG를 열어 큰 크기의 곡선과 작은 크기의 음각을 비교했습니다. 96px 비교는 같은 512px 원본을 축소해 표시합니다.

- P1: 48px에서도 말풍선 꼬리와 굽은 도로의 넓은 아래쪽이 구분됩니다. 도로 끝의 좁은 꼭짓점은 부드러워지지만 도로의 굽은 방향과 흰색 아래 테두리는 남습니다.
- P2: 첫 시안에서 큰 사다리꼴 음각이 문자 A처럼 보여 좁고 긴 차선으로 수정했습니다. 최종 48px에서 사각 천의 출렁임, 깃대, 도로 안쪽 차선이 각각 남습니다. 차선은 약 1.3px 너비라 세 시안 중 가장 작은 디테일입니다.
- P3: 48px에서 왼쪽 창의 빈 면과 오른쪽 반짝임이 분리되고, 반짝임의 네 방향이 남습니다. 형태는 선명하지만 처음 보는 사람이 해설 기능까지 연상하기에는 P1보다 설명이 더 필요합니다.

48px PNG의 음각 안쪽 픽셀이 실제 배경색과 일치하는지도 숫자로 검사했습니다. 전체 검증 수치와 결과물의 SHA-256은 [verification.json](verification.json)에 있습니다.

## 추천

**P1의 회색 타일을 추천합니다.** 말풍선과 도로만으로 길벗의 ‘이동 중 해설’을 함께 보여 주고, 내비게이션 화살표와도 구별됩니다. P2의 가이드 경험과 P3의 창밖 방향 안내보다 서비스의 핵심을 넓게 담으며, 회색 타일이 기본 Pleos 앱 옆에서 가장 자연스럽습니다.

## 파일과 재생성

각 `p1-road-story`, `p2-tour-flag`, `p3-side-window`에 아래 일곱 파일이 있습니다.

- `*-gray.svg`, `*-green.svg`: 512×512 타일
- `*-foreground.svg`: 108×108 adaptive-icon 전경
- `*-gray-512.png`, `*-gray-48.png`, `*-green-512.png`, `*-green-48.png`: 직접 렌더한 PNG

그 밖에 `preview.html`, `README.md`, `inspection.png`, `verification.json`, `build.py`를 포함합니다. Python 3와 Pillow, `rsvg-convert`가 있는 환경에서 `python3 docs/images/icon-concepts/pleos/build.py`를 실행하면 이 폴더 안의 생성물을 재생성하고 검증합니다. 레퍼런스와 기존 시안은 수정하지 않았고, 앱 적용이나 커밋은 하지 않았습니다.
