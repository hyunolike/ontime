# 길벗 최종 아이콘

[실제 Pleos 행과 비교](preview.html) · [크기별 PNG](inspection.png) · [검증 수치](verification.json)

P2의 구멍 있는 사다리꼴 도로를 없애고, 패키지여행 가이드의 사각 깃발을 크게 남겼습니다. 천의 위아래는 완만한 S자 곡선이고 오른쪽 끝은 수직입니다. 바닥 표현은 생략했습니다. 텐트나 삼각 골프 깃발로 읽힐 요소를 줄이고 넓은 흰 면과 굵은 깃대로 Pleos 내비게이션 타일 옆에서 무게를 유지했습니다.

타일은 512×512, 모서리 반경 40px입니다. 녹색은 `#1A9365`, 비교용 회색은 `#353535`, 글리프는 `#FFFFFF`입니다. bbox를 중앙에 놓은 위치에서 오른쪽 1.75dp와 아래쪽 3dp로 광학 보정했습니다. 흰 면의 무게중심은 `(54.011, 52.880)`dp로 가로 중앙에 맞고 세로 중앙보다 1.120dp 위에 있습니다.

| Android 전경 | 108×108dp, viewport 108×108; 선 없이 채운 경로 1개 |

모든 끝점과 베지어 제어점이 안전 원 안에 있습니다. 원의 볼록성과 베지어의 볼록 껍질 성질로 채운 글리프 전체의 포함을 보장합니다. 대비는 sRGB 상대 휘도로 계산했으며 안티앨리어싱 가장자리는 제외합니다. Android의 중앙 72dp가 타일 전체에 대응하도록 SVG도 `viewBox="18 18 72 72"`로 표시합니다. `icon.svg`는 기존 README용 파일과 같은 512 viewBox 형식입니다.

48px PNG를 직접 열어 검토했습니다. 글리프는 약 26.67×26.67px이고 깃대는 4px입니다. 천의 넓은 사각 면, 출렁이는 위아래 가장자리와 수직 끝이 남아 투어 가이드 깃발로 읽힙니다. 이는 시각 검토 결과이며 Android 기기에서 런처를 실행한 검증은 아닙니다. XML 검증은 경로를 SVG로 변환한 뒤 `rsvg-convert 2.58.4`로 렌더한 비교입니다.

주요 파일은 `gilbeot-icon-{green,gray}.svg`, 같은 이름의 `-{512,96,48}.png`, Android용 `ic_launcher_{foreground,monochrome,background}.xml`, README용 `icon.svg`입니다. `android-*-from-xml.svg`와 `android-*.png`는 XML 경로 렌더 증거입니다. `gilbeot-foreground.svg`는 108dp 원본 전경입니다.

재생성: 저장소 루트에서 `python3 docs/images/icon-concepts/pleos/final/build.py`를 실행합니다. Python 3, Pillow와 `rsvg-convert`가 필요하며 생성 파일은 이 폴더에만 씁니다. 상위 P2 파일이나 앱 리소스는 수정하지 않았습니다.
