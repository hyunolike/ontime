# 온타임 소개 영상 계획

- **무엇인가**: 내비의 도착 예정 시각에 공공데이터 예보를 겹쳐, 도착했을 때 그곳이 어떨지 알려 주는 Pleos Connect 차량용 앱.
- **각도**: "도착하면 붐빌까?"라는 질문으로 시작한다. 정체로 도착 시각이 밀리자 예보가 바뀌는 순간이 이 앱의 원리를 한 번에 보여 준다.
- **형식**: 1920×1080, 30fps, 24초.

| 시간 | 장면 | 내용 |
|---|---|---|
| 0.0–12.8 | 앱 | 에뮬레이터에서 녹화한 실제 앱 화면. 보통 → 정체로 14:04 도착 → 붐빔 → 제안 → "그렇게 해 줘" → 여유 |
| 12.5–16.8 | 소개 | 아이콘과 이름, "내비는 언제 도착하는지, 온타임은 도착했을 때 그곳이 어떨지." |
| 16.5–20.3 | 증거 | Pleos Connect 에뮬레이터에서 실제 내비와 나란히 띄운 화면 |
| 20.1–24.0 | 끝 | 이름, 공모전 출품작, 저장소 주소 |

## 사실 관계

- 앞부분은 `fake` release 빌드를 Pleos Connect 에뮬레이터에서 실행해 녹화한 화면이다. 주행 시간과 혼잡도는 예시 데이터이고, 화면과 자막에 그렇게 표시했다.
- 증거 장면은 `pleos` 빌드가 실제 내비에서 남은 시간을 받아 계산한 화면이다(공항 일정).
- "그렇게 해 줘" 말풍선은 사용 흐름을 보여 준 것이다. 음성 인식은 아직 동작하지 않는다.
