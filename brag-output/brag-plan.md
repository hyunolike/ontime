# 길벗 소개 영상 계획

- **무엇인가**: 차가 여행 가이드가 되는 Pleos Connect 차량용 앱. 곧 지나갈 곳의 이야기를 미리 들려주고, 회전 앞에서는 말을 멈춘다.
- **각도**: 기능을 설명하지 않고 앱이 하는 일을 순서대로 보여 준다. 화면 오른쪽 자막이 차만 할 수 있는 점을 한 줄씩 짚는다.
- **형식**: 1920×1080, 30fps, 26초.

| 시간 | 장면 |
|---|---|
| 0.0–3.3 | "5분 뒤 오른쪽 창밖, 대릉원" 이야기와 사진 |
| 3.3–8.9 | "들러 볼까요?"에 볼거리와 늦어지는 시간, "들르기"를 눌러 경유지 추가 |
| 8.9–12.0 | 우회전 앞에서 "잠시 쉽니다" |
| 12.0–15.0 | 회전을 지나 "왼쪽 창밖, 첨성대" |
| 15.0–18.8 | 대릉원 도착, 방문 도장 |
| 18.5–22.5 | 이름과 한 줄 소개 |
| 22.2–26.0 | 끝 화면 |

## 사실 관계

- 앱 화면은 `fake` release 빌드를 Pleos Connect 에뮬레이터에서 녹화한 것이다. 60초 녹화에서 다섯 구간을 잘라 이었다.
- 거리와 해설, 들르는 데 드는 시간은 예시 데이터이고, 화면과 자막에 그렇게 표시했다.
- "들르기"는 녹화 중에 실제로 누른 것이다. 녹화에는 터치 표시가 남지 않아 누른 자리에 원을 덧그렸다.
- 음성은 나오지 않는다. 해설은 앱 화면의 자막이다.
