# 온타임 소개 영상 계획

- **무엇인가**: 놓치면 안 되는 시각(수속 마감)까지 남은 여유를 주행 중에 숫자 하나로 보여 주는 Pleos Connect 차량용 앱.
- **누구에게**: 공항이나 기차역처럼 늦으면 안 되는 곳에 차로 가는 운전자.
- **다른 점**: 도착 시각이 아니라 마감까지의 여유를 보여 주고, 여유가 줄면 주차장을 바꾸자고 말로 제안한다.
- **각도**: 숫자가 떨어지는 순간이 곧 문제 정의다. "+28분"이 사고 정체로 "+9분"이 되는 장면으로 시작한다.
- **증거**: 실제 Pleos Connect 에뮬레이터에서 내비와 나란히 띄운 화면. 내비의 남은 시간으로 계산한다는 점을 보여 준다.
- **톤**: default. 앱과 같은 어두운 바탕, Asta Sans, 상태색(초록, 주황, 빨강, 파랑)만 강조색으로 쓴다.
- **형식**: 1920×1080, 30fps, 22초.

## 장면

| 시간 | 장면 | 내용 |
|---|---|---|
| 0.0–3.8 | 훅 | 앱 주행 화면을 그대로 옮긴 장면. "+28분"이 "+9분"으로 줄고 초록이 주황으로 바뀐다. "고속도로 사고 정체로 도착이 19분 늦어졌습니다" |
| 3.8–7.2 | 소개 | 앱 아이콘과 "온타임", "마감까지 남은 여유를, 숫자 하나로." |
| 7.2–12.6 | 핵심 동작 | 제안 띠 "단기주차장으로 바꾸면 12분을 아낄 수 있습니다", 말풍선 "그렇게 해 줘", "+21분"과 목적지 변경 |
| 12.5–18.5 | 증거 | 실제 에뮬레이터 화면에서 내비의 남은 시간, 온타임의 여유, 주차장 비교를 차례로 짚는다 |
| 18.2–22.0 | 끝 | 아이콘이 그려지고 "온타임 OnTime", 공모전 출품작, 저장소 주소 |

## 사실 관계

- 앱 화면 장면의 문구와 숫자(+28, +9, +21분, 12분 단축, 마감 15:55)는 앱의 시연 재생 시나리오와 같다. 화면의 "시연 재생" 표시도 그대로 두었다.
- 증거 장면은 2026-11-14 11:17 Pleos Connect Emulator v2.1.0에서 `pleos` 빌드를 실행해 찍은 실제 화면이다(내비 1시간 24분, 온타임 −13분, 단기주차장 −6분).
- "그렇게 해 줘" 말풍선은 앱이 안내하는 사용 흐름을 보여 준 것이다. 에뮬레이터에서 음성 인식은 아직 동작하지 않는다.
